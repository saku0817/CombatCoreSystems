# CombatCoreSystems v1.4.0

## 変更内容・理由・差異

| 箇所 | 変更前 | 変更後 | 理由・差異 |
| --- | --- | --- | --- |
| ATK | ホットバー内の有効なCCS武器を加算 | 利き手とオフハンドの有効なCCS武器だけを合算 | 指定された手持ち基準に変更。所持しているだけの武器は無効 |
| スキル操作 | しゃがみ＋攻撃 | 手持ち武器のドロップ操作 | 直感的な発動。スキルのあるCCS武器は実際には落ちない |
| 必殺技操作 | しゃがみ＋使用 | しゃがみ＋攻撃 | 同時の通常攻撃をキャンセル。CT・条件不足時も通常攻撃にすり替わらない |
| スタック表示 | 技名・CT中心、別武器の状態が選ばれる場合あり | 現在の利き手武器の残数／最大数 | 複数スタックの技は戦闘外でも表示 |
| 未指定カテゴリ | 近接か遠距離のみ | UNCATEGORIZEDを追加 | 同カテゴリの複数所持監査から除外 |
| 通常攻撃属性 | 神の心からの変更のみ | 武器にも設定可能 | 神の心の上書きルールは引き続き優先 |
| 天賦 | 未対応 | 指定した手で所持中のステータス補正 | 例の最大HP＋50%を再現。持ち替えで回復せず、現在HPを保持（上限超過分は切り詰め） |
| 技効果 | ダメージ中心 | 現在HP消費、自分・対象へのバフ／デバフ付与 | SELFの補助技はdamage-enabled: falseで自傷しない |
| 対象不在時のコスト | 範囲内が空でも技のCTが進む場合あり | 有効対象を確定してからHP・スタックを消費 | 不発時の意図しない消費を防止 |
| 複合式 | 1つの参照値と倍率 | 複数の参照値・倍率・項ごとの属性補正 | 炎属性補正を必要な項だけに適用し、二重適用しない |
| 落日 | 未定義 | buffs.ymlで攻撃力-30%、被攻撃時に防御力40%無視、3秒 | 武器には効果IDのみ記述。プレイヤー・Mob双方に適用 |
| エフェクト | 武器ごとの設定なし | 通常攻撃／スキル／必殺技ごとにパーティクル・サウンド | データ不要のパーティクルに限定し、過大な設定を読込時に拒否 |
| ツールチップ | 自由loreが先、技の機械的な数値表示 | 指定のカテゴリ→レベル→限界突破→ATK→属性補正→装備可能Lv→天賦→スキル→必殺技→自由lore | 名前・説明・テンプレートを編集可能。武器ATK表示だけ四捨五入し、計算精度は維持 |

## ATKとダメージ式

```
ATK = (プレイヤー基礎ATK + 両手の有効CCS武器ATK合計 + 利き手バニラ武器換算ATK)
      × (1 + ATK_PERCENT合計) + ATK_FLAT合計
```

「有効」は装備可能プレイヤーレベル内の武器。CCS武器をバニラ換算へ重複加算しません。ホットバーの所持数監査は従来どおりですが、所持とステータス有効化は別です。

複合式の各項は `参照値 × 項のmultiplier × (1 + 指定した属性ダメージ補正)`。`bonus-attribute: PHYSICAL` は属性補正なし。合計に技の `multiplier` を掛けます。`reference` は `HP`（最大HP）／`ATK`／`DEF`。参照値はいずれも装備・バフ込みのステータスです。

例の必殺技の合算値：`ATK × 2 + ATK × 1 × (1 + FIRE_DAMAGE)`。ATK100、FIRE_DAMAGE0.15なら315。**その後、既存の防御係数・全体倍率・対象の炎耐性・会心を適用**します。攻撃属性をFIREにしても、合算値への炎ダメージ補正の再適用はありません。表示・HP減算・会心判定は合計に対して1回です。属性付着・反応は従来どおりです。

落日が付いた対象への防御計算：`有効防御力 × (1 - clamp(DEF_IGNORED_WHEN_HIT合計, 0, 1))`。0.4なら60%だけを防御係数に渡します。DEF_DOWNとは別の乗算段階です。固定ダメージや従来から防御力を使わない属性反応の式には掛けません。

## weapons.yml 新規キー一覧

既存キーも引き続き有効。以下のパスは `weapons.<武器ID>.` からの相対パスです。

| キー | 値・既定値 | 説明 |
| --- | --- | --- |
| category / type | MELEE / RANGED / UNCATEGORIZED | 大小文字を区別しない。両方あるとtype優先 |
| normal-attack.attribute | PHYSICAL | 通常攻撃属性。FIRE/WATER/WIND/THUNDER/MOON/PHYSICAL |
| talent.name | 天賦 | MiniMessage対応の名前 |
| talent.description | 空リスト | 文字列または複数行リスト。効果の実装には使わない |
| talent.hand | MAIN_HAND | MAIN_HAND/OFF_HAND/EITHER_HAND |
| talent.multiplier | 1.0 | 天賦modifiersの全値に掛ける倍率 |
| talent.modifiers.<StatKey> | なし | HP_PERCENT: 0.5など、既存ステータスキー |
| skill.description / ultimate.description | 空リスト | 文字列またはMiniMessageの複数行リスト |
| skill.damage-enabled / ultimate.damage-enabled | true | falseで技ダメージを出さず、バフなどの効果のみ発動 |
| skill.cost.current-hp-percent / ultimate.cost.current-hp-percent | 0 | 発動時の現在HPから消費。0以上1未満 |
| skill.self-effects / ultimate.self-effects | [] | 自分に付与するbuffs.ymlのID一覧 |
| skill.target-effects / ultimate.target-effects | [] | 技の有効な対象に付与するbuffs.ymlのID一覧 |
| skill.damage-components / ultimate.damage-components | 未指定 | 設定する場合は1項以上のリスト。未指定なら既存の単一式 |
| 上記リスト内reference | ATK | HP/ATK/DEF |
| 上記リスト内multiplier | 1.0 | 項の倍率。2なら200% |
| 上記リスト内bonus-attribute | PHYSICAL | その項だけに掛ける属性補正。PHYSICALなら補正なし |
| normal-attack.visual / skill.visual / ultimate.visual | 未指定 | 下表のエフェクト設定 |

各技の既存 `multiplier`、`reference`、`attribute`、`cooldown-seconds`、`charges`、`radius`、`target`、`conditions` は継続。`conditions.min-hp-percent: 0.3` は最大HPに対する現在HPの割合で、HP消費量とは別。倍率はダメージに掛かり、バフの値はbuffs.ymlで管理します。

| visual内キー | 既定値 | 範囲・例 |
| --- | --- | --- |
| particle | 空（なし） | FLAME、ENCHANTなどデータ不要のBukkit Particle名。DUST等は未対応として読込を拒否 |
| count | 20 | 0～500 |
| spread | 0.5 | 0～16ブロック |
| sound | 空（なし） | minecraft:entity.blaze.shoot等。実在するキーを使用 |
| volume | 1.0 | 0～4 |
| pitch | 1.0 | 0～2 |

## バフ・デバフと実装例

同梱weapons.ymlの `guiding_star` と、buffs.ymlの `departure_crit`・`sunset` が動作例です。既存の設定ファイルは上書きしないため、更新時はそれぞれのルートへ該当定義を追加してください。武器だけを追加すると、未定義のバフ参照としてエラーになります。

完全な設定例：[weapons.yml](https://github.com/saku0817/CombatCoreSystems/blob/v1.4.0/src/main/resources/weapons.yml)、[buffs.yml](https://github.com/saku0817/CombatCoreSystems/blob/v1.4.0/src/main/resources/buffs.yml)。既存ファイル全体を置き換えず、必要な定義を追加してください。

「出航」は現在HPの30%を消費し、会心ダメージを48パーセントポイント増加。最大HP30%以上が必要です。例：最大HP1000・現在HP400なら120消費、残280です。

「落日」は `buffs.sunset` に `duration: 3`、`modifiers.percent.ATK_PERCENT: -0.3`、`modifiers.percent.DEF_IGNORED_WHEN_HIT: 0.4` を記述しています。武器側は `target-effects: [sunset]` のみ。Mobの効果はロード中の個体で保持され、死亡・アンロード・再起動で破棄します。今回Mob戦闘計算に接続した補正はATK_FLAT、ATK_PERCENT、DEF_FLAT、DEF_PERCENT、DEF_DOWN、DEF_IGNORED_WHEN_HITです。

## 表示・操作設定

config.yml: `controls.drop-skill` と `controls.sneak-attack-ultimate`（各true）。旧 `controls.sneak-inputs` は新操作には使いません。`/ccs skill`・`/ccs ultimate` は補助操作として継続します。

手持ちドロップでは、技が未設定の武器や通常アイテムは従来どおり落とせます。技のある武器はCT・発動条件不足でも落としません。インベントリ内のドロップ操作・カーソル破棄は技の発動から除外します。ドロップ復元待ちの1tick内に別スロットへ持ち替えた場合は安全のため発動しません。

messages.ymlの `weapon-tooltip.header`（行リスト）、`categories.<カテゴリ>`、`colors.<属性>`、`talent-title`、`skill-title`、`ultimate-title` を編集できます。置換値は `<category>`、`<exp_remaining>`、`<level>`、`<break>`、`<attack>`、`<attribute_color>`／`</attribute_color>`、`<attribute>`、`<bonus>`、`<min_level>`、`<max_level>`、技見出しの `<name>`。最大武器Lv100、最大限界突破5は既存仕様のままです。

説明未指定の既存技は `weapon-tooltip.ability-summary` で数値要約を表示します（`<reference>`、`<multiplier>`、`<attribute>`、`<cooldown>`、`<charges>`）。CT中の発動通知は `skill-failure.cooldown` の `<seconds>` で編集可能です。

レベル行のhoverイベントは指定どおり設定しますが、**アイテムツールチップ内での追加ホバー表示はクライアント上では未確認**です。確実に読める通常行が必要なら、headerへ `<gray>次のレベルまであと <exp_remaining></gray>` を追加できます。

gui.ymlの `hud.ability-actionbar`（戦闘外のスタック表示）、`hud.ability-ready`、`hud.ability-undefined`、`hud.ability-cooldown`（`<seconds>`）、`hud.ability-stacks`（`<remaining>`／`<maximum>`／`<status>`）で表示を編集できます。既存の `hud.combat-actionbar` の `<skill_status>`・`<ultimate_status>` にもスタックを反映します。
