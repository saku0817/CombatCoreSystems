# CombatCoreSystems v1.4.1

## 変更前・変更後と理由

| 箇所 | 変更前 | 変更後・理由 |
| --- | --- | --- |
| ドロップ入力 | インベントリを閉じると無条件に直後のドロップを除外 | カーソルに実物がある場合のみ除外。空カーソルの画面終了による誤除外を防止 |
| 発動失敗 | アクションバーのみ／復元不一致は無表示 | 条件不足や手持ち復元失敗を本人のチャットにも表示。常時HUDによる見落としを防止 |
| 入力診断 | イベント分類が不明 | 任意でドロップ分類・キャンセル状態・権限・武器IDをログ出力 |
| 装備同期 | 同一プレイヤーに複数の次tick同期を予約 | 次tickまでの予約を1つに統合。最終的なインベントリを監査 |
| 更新負荷 | 同一アイテムメタ・攻撃属性値も書き込み | 値が変わった場合のみ書き込み。計算式と更新結果は維持 |
| 視線HUD | 候補Mobごとに遮蔽判定 | 最も近い照準対象にのみ遮蔽判定。壁越しには表示しない |
| ダメージ | 通常・会心・反応の固定色 | ダメージ数値は属性色。反応の数値は構成する2属性のグラデーション |
| 素材 | 自由loreのみ | PLAYER／WEAPON／EQUIPMENTから強化用途を追加表示 |
| アクションバー | 非戦闘時は複数スタック等の場合のみ表示 | スキル・必殺技を常時表示。戦闘中の文字は戦闘中のみ。HUD無効設定は尊重 |
| 武器ツールチップ | 名前の次にカテゴリ | 名前とカテゴリの間にレア度の数だけ★を表示 |
| 図鑑一覧 | ★と数字 | 名前と色付きの★のみ |
| 武器詳細 | 武器アイコン1つ | 天賦・スキル・必殺技・説明を静的な名前とloreで表示。押しても遷移しない |
| ステータス | 左寄りの値の羅列 | 額縁、中央の本人プロフィール、体力／攻撃／防御、会心、属性の段構成 |
| 頭アイコン | 所有者未指定 | 本人の頭。パーティ欄は表示対象メンバーの頭。外部スキン取得の同期ネットワーク処理は追加しない |
| 発動通知 | なし | スキル・必殺技成功時と天賦の所持条件成立時に本人だけへ通知。天賦は継続中に連打しない |
| 表示の保守 | サイドバー行数変更で例外の可能性 | reload後の行数変更に合わせ再生成。ダメージ表示の所有者管理も解放 |

根本的なATK・防御・耐性・会心式、強化や所持制限は変更していません。

## 必殺技の確定計算

ATK100・炎属性ダメージ補正+15%の場合、`100×2 + 100×1×(1+0.15) = 315`。
炎属性補正は後半の項だけに適用します。合計315に共通の防御係数・設定倍率・耐性を適用し、その後に会心倍率を適用します。防御力の数値を315から直接引く方式には変更していません。
共通倍率 `damage.global-multiplier` は従来通りです。計算の参照ステータスは `damage-components[].reference`（HP／ATK／DEF）で設定します。

## 設定キー

既存ymlは上書きしません。追加キーを省略しても既定値で動きます。

| ファイル／キー | 値・既定動作 |
| --- | --- |
| config.yml: controls.debug-inputs | false。調査中だけtrue |
| config.yml: controls.failure-chat | true。発動失敗を本人に表示 |
| config.yml: attribute-colors.FIRE/WATER/WIND/THUNDER/MOON/PHYSICAL | 色。武器表示・ダメージ表示で共用。PHYSICAL省略時白 |
| config.yml: rarity-colors.1～5 | レア度の色。既存キーを使用 |
| weapons.yml: weapons.ID.enchantment-glint | false。trueでエンチャント光 |
| equipment.yml: equipment.ID.enchantment-glint | false。equipments.ymlの互換定義にも適用 |
| divine_hearts.yml: divine-hearts.ID.enchantment-glint | false |
| levels.yml: materials.ID.enchantment-glint | false |
| gui.yml: enchantment-glint | false。GUI作成アイコンの共通設定 |
| gui.yml: main-menu.entries.ID.enchantment-glint | 任意。メニュー項目だけ上書き |
| gui.yml: stats.title / border-material | 画面タイトル／GRAY_STAINED_GLASS_PANE |
| gui.yml: stats.health-name / attack-name / defense-name / critical-name | ステータスの見出し |
| gui.yml: encyclopedia.talent / skill / ultimate / description / undefined | 詳細カテゴリ名／未設定の表示 |
| messages.yml: ability-announcement.skill / ultimate / talent | MiniMessage。`<name>`を技名に置換。空文字で省略 |
| messages.yml: material-tooltip.usage | `<target>`を用途名に置換 |
| messages.yml: material-tooltip.targets.PLAYER / WEAPON / EQUIPMENT | プレイヤー／武器／装備 |
| messages.yml: skill-failure.hand-changed / hand-restore | 持ち替え・復元失敗メッセージ |

実物の武器・装備・神の心の更新は従来の装備同期時に反映します。素材は新しく生成する物に用途・光設定が反映されます。既存素材を変更する場合は管理者が同IDで再発行してください。全バニラアイテムを一律に変更する設定ではありません。

```yaml
# weapons.yml の各武器定義内（equipment、divine-hearts、materialsも同じ階層）
enchantment-glint: true
```

メニューの図鑑は同梱設定で既にKNOWLEDGE_BOOKです。古い設定のサーバーでは `gui.yml` の `main-menu.entries.encyclopedia.icon: KNOWLEDGE_BOOK` に変更してください。任意に編集されたアイコンは自動で上書きしません。

## BEで発動しない場合

手持ちのCCS武器のドロップがスキル入力です。インベントリからの破棄は従来の指定通り通常の破棄で、スキル入力ではありません。
`controls.debug-inputs: true` にして `/ccsadmin reload` 後、手から一度だけドロップし、`[skill-input]` 行と本人チャットの失敗理由を確認してください。調査後はfalseに戻します。
Geyserがその操作をインベントリクリックに翻訳した場合は破棄扱いになります。BE実機での再現・解消は未確認であり、この版の変更だけで今回の不発が解消したとは断定しません。継続する場合はGeyser/Floodgateのバージョンとログで入力経路を特定します。
