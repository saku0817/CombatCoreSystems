# v1.3.1 修正・変更記録

## 操作

- スキル：CCS武器を持って **しゃがみ＋攻撃**。`/ccs skill` も使用できます。
- 必殺技：CCS武器を持って **しゃがみ＋使用**。`/ccs ultimate` も使用できます。
- 装備：`/ccs open equipments` → 空の部位（神の心を含む）をタップ → 所持品の候補を選択。装備中アイコンのタップで解除します。
- 装備変更は戦闘中にはできません。神の心・残響の実物は所持品に残ります。実物を手放すと装備登録は解除されます。

Java版の左右クリック区別はGUI操作に必須ではありません。戦闘入力は各クライアントの攻撃／使用操作を利用し、コマンドも代替手段として残します。

## 変更箇所・理由・変更前後・差異

| 変更箇所 | 理由 | v1.3.0まで | v1.3.1 | 差異・互換性 |
|---|---|---|---|---|
| 装備候補一覧 | 空IDが神心のルート設定に一致し、空スロットで例外 | 空きがあると `stack.clone()` で停止する場合がある | null・空気・空IDを除外 | 所持アイテムは削除しない |
| 装備画面 | 実際の防具との表示不一致 | CCS防具のみ表示、バニラ防具は未装備表示 | 実物のバニラ防具も表示し「装備中」を追記 | バニラ防具のDEF換算方式は維持 |
| 空の装備枠 | 神心等の装備導線が分かりにくい | 空枠を押しても選択画面に進まない | 対応する部位の候補一覧へ進む | 既存の「所持品から装備」も維持 |
| 装備選択判定 | 遅延処理中のイベント値への依存を減らす | 後からクリックイベントのアイテムを参照 | 描画時の個体IDと現在の所持品を照合 | 選択後のすり替わりを拒否 |
| スキル入力 | 前回の操作廃止を撤回 | コマンドのみ | しゃがみ＋攻撃／使用を復旧、コマンドも併用 | 攻撃は通常ダメージ処理より前に受付。メインハンド限定・同一tick重複抑制 |
| 発動失敗案内 | 原因が分からない | 無言または共通エラー | 読込中・未登録・装備レベル・未設定・条件・対象を区別 | 設定のレベル条件を勝手に緩和しない |
| 使用武器 | 持っていない以前の武器で技が使える不整合 | 手持ちIDがなければ戦闘状態の武器IDへフォールバック | 手持ちのCCS武器を使用 | コマンドでも手持ちが必要 |
| 未設定スキル | 架空の技がLoreに現れる | skill/ultimateがなくても仮の技を作成 | 未設定は未設定として案内 | 設定済みの技には影響しない |
| 属性ボーナス読込 | 過去のWiki例と実装の不一致 | `FIRE_DAMAGE` が無属性扱い | `FIRE` と `FIRE_DAMAGE`（ハイフン表記も）に互換対応 | 管理用キーとプレイヤー向け表示を分離 |
| Minecraft攻撃力への反映 | ネイティブ武器補正の二重加算 | CCS最終ATKをbase値へ直接設定 | ネイティブ補正を逆算したbase値へ設定 | CCSの基本ATK式は変更なし |
| ステータス画面の攻撃力説明 | 武器が無効な理由を確認可能にする | 合計ATKのみ | ホットバー武器ごとの加算値と装備レベル不足を表示 | 計算方法は変更しない |
| 装備サブステータス | 未開放表示なのに効果が加算される | 全候補を加算 | 開放済みのみ加算 | 誤って加算されていたATK等は減少する場合がある |
| 表示名 | 内部キーがそのままプレイヤーに見える | `FIRE_DAMAGE`、`HEAD`等 | 属性ダメージ・耐性・部位・条件を日本語化、割合を%表示 | 保存IDは変更なし。`display-names`で上書き可能 |
| 神心Lore | 元仕様ではLvなし | Lv.1を表示 | 神心のLv表示を除去 | 成長仕様の追加はしない |
| 装備ファイル名 | 複数形との取り違え対策 | `equipment.yml`のみ | 追加で`equipments.yml`も互換読込 | 正式名は単数形。重複IDはエラー、再読込時は旧設定維持 |
| 設定コメント | 1行例だけでは構造が分かりにくい | 短い例 | 防具・残響・神心の複数行例と操作説明 | 既存の利用者YAMLは上書きしない |
| 未対応の限界突破キー | 無視される設定を発見しやすくする | `atk-percent`を無言で無視 | 起動・再読込時に警告 | 新しい攻撃力成長ルールは独断で追加しない |

## 提供された設定の確認結果

`flame_blade` は `equip-level.min: 20`、武器Lv.1の攻撃力18、武器Lv.100の攻撃力420です。

- プレイヤーLv.19以下：この武器のATK・属性ボーナスは加算対象外、スキルも使用不可（既存の条件）。
- プレイヤーLv.20・武器Lv.1・新生回帰なし・他補正なし：既定のプレイヤー基礎ATK40 + 武器ATK18 = 最終ATK58。
- `attribute-bonus.type: FIRE_DAMAGE` はv1.3.1で炎属性ボーナス15%として読み取れます。新規作成では `FIRE` を推奨します。
- `divine-heart-flame` の `FIRE_DAMAGE: 0.2` は炎属性ダメージ20%の補正です。これだけでは通常攻撃は炎属性に変わりません。属性変換には `rules.normal-attack-attribute: FIRE` が必要です。
- `limit-breaks.1.atk-percent: 0.05` は未対応です。攻撃力の限界突破成長を追加する場合は、基本設計への追加として別途合意します。

基本式は `(プレイヤー基礎ATK + 有効なホットバーCCS武器ATK合計 + 手持ちバニラ武器換算ATK) × (1 + ATK割合補正) + ATK固定補正` のままです。表示ATKと実ダメージは、攻撃チャージ・技倍率・防御係数・属性補正・耐性・会心等があるため同値とは限りません。

## 新規設定キー

| ファイル | キー | 内容 |
|---|---|---|
| config.yml | `controls.sneak-inputs` | 既定true。しゃがみ入力を有効化。falseでもコマンドは使用可能 |
| gui.yml | `equipment.equipped` | 装備中アイコンの案内文 |

| messages.yml | `skill-failure.loading` | プレイヤーデータ読込中 |
| messages.yml | `skill-failure.weapon` | 手持ちCCS武器なし |
| messages.yml | `skill-failure.unknown-weapon` | 定義未登録 |
| messages.yml | `skill-failure.equip-level` | 装備レベル不適合 |
| messages.yml | `skill-failure.undefined` | 技未定義 |
| messages.yml | `skill-failure.conditions` | 条件不成立 |
| messages.yml | `skill-failure.target` | 対象未検出 |

## 更新と検証

設定とデータをバックアップし、サーバーを停止してJARを置き換え、再起動してください。既存YAMLは上書きしないため、新しいコメント例はJAR内の `equipment.yml`・`divine_hearts.yml` またはリポジトリの `src/main/resources` を参照してください。

自動テストでは、空ID誤判定・神心スロット判定・属性キー互換・Lv条件・武器成長と攻撃力式・ネイティブ補正の逆算・日本語名・しゃがみイベント登録を検証します。自動テストやサーバー起動確認は、実際のJava版／統合版クライアントでの操作試験を代替するものではありません。

配布ビルドは自動テスト20件合格。提供設定3点をコピーした専用環境でPaper 26.2-121／Java 25の起動・SQLite接続・設定再読込・正常終了を確認しました。Paper 26.2-103およびJava版／統合版クライアントでの実機操作試験は未実施です。
