# CombatCoreSystems v1.3.0

Paper 26.2 / Java 25。v1.2.xのプレイヤーデータ・設定を引き継ぎます。サーバーを停止し、設定とデータをバックアップしてから旧JARをv1.3.0 JARへ置き換えてください。旧JARと新JARを同時に配置しないでください。

## 操作

GUIは通常クリック・タップだけで操作できます。左右クリックの区別やShiftキーは不要です。

| 操作 | コマンド・手順 |
|---|---|
| 総合メニュー | `/ccs menu` |
| 装備 | `/ccs open equipments` → 所持品から装備を選ぶ → 対象をタップ |
| 解除 | 装備画面の装備済みアイコンをタップ。防具を戻す空きが必要 |
| 強化 | `/ccs open enhancement` → 対象選択 → 素材の上の「1個増やす」／下の「1個減らす」→ 確定 |
| 変換 | 強化 → 変換 → 素材 → 実物→数値／数値→実物／上級／下級 |
| 図鑑 | `/ccs open encyclopedia` → カテゴリ → 項目 → 詳細。未発見Mobは詳細を開けない |
| パーティ | `/ccs open party` → 作成、届いた招待、承認・辞退、退出。リーダーは招待・メンバー選択による管理・解散 |
| スキル | CCS武器をメインハンドに持ち、対象を見て `/ccs skill` |
| 必殺技 | CCS武器をメインハンドに持ち、対象を見て `/ccs ultimate` |
| 設定 | `/ccs setting` または `/ccs open settings`。Backで総合メニューへ戻る |

スキル・必殺技コマンドは戦闘中も使えます。CCS武器、装備レベル、発動条件、射線、チャージ・CTを確認してください。単体対象スキルで対象が見つからなければCTを消費しません。GUI下側の所持品は整理でき、上側のメニューへ入れようとしたアイテムは所持品へ戻します。空きがない場合はカーソルに保持します。Shift移動・上側へのドラッグ・GUIアイコン回収は無効です。

防具は実際の防具スロットと連動します。共鳴・神心は所持する個体を登録し、その実物を所持品から失うと登録を解除します。ホットバーのCCS武器は種別ごとに1本、装備レベル範囲内の武器ATKを加算します。オフハンドは重複監査対象ですがATK加算対象はホットバーです。

## ダメージと討伐報酬

通常近接攻撃の倍率は `0.2 + 0.8 × 攻撃充填率²` です。攻撃直前の値を使用します。充填率0%で20%、50%で40%、100%で100%になります。弓は発射時の引き絞り倍率を反映します。スキル・必殺技の倍率は個別定義を使用します。

`最終ATK = (プレイヤー基礎ATK + 対象CCS武器ATK合計 + 手持ちバニラ武器換算ATK) × (1 + ATK_PERCENT) + ATK_FLAT`

CCS武器を手に持つ場合、その武器のバニラATKは二重加算しません。武器ATKは `level-1 + (level-100 − level-1) × (武器Lv − 1) / 99` です。

通常攻撃・スキル・属性反応でプレイヤーを討伐者として記録します。独自EXPは死亡イベントで一度付与し、Minecraft標準EXPとは連動しません。個別Mob設定の `custom-exp` と `drop-custom-exp` が優先されます。

```yaml
# mobs.yml。未登録バニラMobのみ対象。0またはfalseで無効化。
vanilla-defaults:
  custom-exp: 5
  drop-custom-exp: true
```

## YAMLの共通ルールと武器例

UTF-8、2スペースインデント、ブロック形式を標準とします。設定キーはハイフン区切り、素材・属性・種別の列挙値は大文字、IDは英小文字・数字・アンダースコアを推奨します。`data-version`は設定形式の番号でありプラグインのバージョンではありません。既存ファイルは上書きしません。新しいキーを省略した場合は既定値で動作します。

```yaml
data-version: 1
weapons:
  flame_sword:
    name: "<red>炎剣</red>"
    material: IRON_SWORD
    type: MELEE
    rarity: 4
    base-atk:
      level-1: 20
      level-100: 200
    equip-level:
      min: 1
      max: 100
    lore:
      - "<gray>炎の力を宿す剣</gray>"
    skill:
      name: "炎撃"
      reference: ATK
      multiplier: 2.0
      attribute: FIRE
      cooldown-seconds: 8
      charges: 1
      radius: 0
      target: ENEMY
      conditions:
        requires-target: true
    ultimate:
      name: "炎嵐"
      reference: ATK
      multiplier: 4.0
      attribute: FIRE
      cooldown-seconds: 30
      charges: 1
      radius: 3
      target: ENEMY
```

`type`、`attribute`、`cooldown-seconds`を推奨します。旧`category`、`element`、`cooldown`も読み込みます。両方ある場合は推奨キーを優先します。限界突破の`skill.cooldown-seconds`・`ultimate.cooldown-seconds`も同様です。

## 追加設定キー

| ファイル・キー | 既定値・用途 |
|---|---|
| `config.yml: hud.target-bossbar-enabled` | `true`。注視MobのHPバー |
| `config.yml: hud.target-range` | `24.0`。検出距離（ブロック） |
| `mobs.yml: vanilla-defaults.custom-exp` | `5`。未登録Mobの独自EXP |
| `mobs.yml: vanilla-defaults.drop-custom-exp` | `true`。未登録Mobの報酬有効化 |
| `gui.yml: enhancement.tap-controls, add-one, remove-one` | 素材数操作の表示文 |
| `gui.yml: enhancement.conversion-select, deposit, withdraw, upgrade-tier, downgrade-tier` | 変換画面の表示文 |
| `gui.yml: equipment.select, list-title` | 装備選択表示 |
| `gui.yml: encyclopedia.detail-title` | 図鑑詳細タイトル |
| `gui.yml: party.leave, invite, disband, invitations, actions-title, kick, transfer, accept, decline, confirm, invited` | パーティ表示文 |
| `gui.yml: hud.target-health` | `<hp> / <max_hp>`。対象HPの表示形式 |
| `messages.yml: item-lore.effect` | 神心・セット効果の説明。`<label>`・`<key>`・`<value>`を置換 |

## 戦闘退出違反

各違反の発生時刻を保存し、その24時間後に該当する1件が失効します。オフラインでも実時間で計算し、ログイン時・参照時に反映します。未失効の違反が4件に達すると従来どおりプレイヤーLvが1下がり、件数がリセットされます。v1.2.xの件数には個別時刻がないため、保存済み最終保存時刻（なければ移行時刻）を基準に移行します。

## debug

管理権限 `combatcoresystems.admin.debug`（または`combatcoresystems.admin.*`）を持つプレイヤーがゲーム内で実行します。

| コマンド | 動作 |
|---|---|
| `/ccsadmin debug on` | 自分の攻撃ログを10分間有効化 |
| `/ccsadmin debug on 30s` | 30秒間有効化 |
| `/ccsadmin debug off` | 記録停止、予約解除 |
| `/ccsadmin debug status` | ON/OFF、予約有無、保存先を表示 |
| `/ccsadmin debug schedule 5m 10m` | 5分後から10分間記録 |
| `/ccsadmin debug cancel` | 記録停止、予約解除 |

時間は正の整数と`s`（秒）・`m`（分）・`h`（時間）・`d`（日）を組み合わせます。有効化後に通常攻撃やスキルを使うと、発生元、対象UUID、倍率、最終ダメージ、会心をチャット・コンソール・`plugins/CombatCoreSystems/logs/debug/YYYY-MM-DD.log`へ出力します。まだ発生していない攻撃の記録や、他の全プレイヤーを対象にした記録ではありません。

旧 `/ccs encyclopedia`・`/ccs party`・`/ccs debug` は移動しました。パーティのテキスト操作は `/ccs open party invite <player>`、`accept <player>`、`decline <player>`、`leave`、`kick <player>`、`leader <player>`、`disband`、`list`、`chat <message>`です。
